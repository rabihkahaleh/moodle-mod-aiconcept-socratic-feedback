This is a research-grade Moodle activity module that delivers instructor-moderated, misconception-specific AI feedback to students during code debugging tasks.

The plugin implements a Socratic tutoring model:
AI responds to student code one blocking issue at a time, prompting the learner to reason, revise, and resubmit.
When the student believes the code is correct, the submission is routed to the instructor dashboard for moderation and approval.

This project is designed for feasibility studies in conceptual change and AI-augmented formative assessment.

core features

GPT-based Socratic dialogue on student code

automatic detection of blocking errors and misconceptions

instructor dashboard for moderation and approval

knowledge-base entry creation from instructor edits

Moodle 4.3+ compatible module

academic use

This plugin was used in a feasibility study investigating AI-augmented feedback for first-year programming courses.
